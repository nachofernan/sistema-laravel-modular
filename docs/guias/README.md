# Guías operativas y de referencia

Manuales de sistemas y features **vigentes** de la plataforma. A diferencia de `docs/modulos/` (que
describe áreas funcionales completas), acá van guías de un sistema transversal o una feature puntual.

| Guía | De qué trata |
|------|--------------|
| [`EMAIL_SYSTEM.md`](EMAIL_SYSTEM.md) | Sistema de envío de emails: arquitectura, colas, filtros de dominio, rate limiting, `email_logs` |
| [`MODO_MANTENIMIENTO.md`](MODO_MANTENIMIENTO.md) | Los dos sistemas de modo mantenimiento (personalizado con acceso autorizado, y nativo de Laravel) |
| [`SIDEBAR_DINAMICO.md`](SIDEBAR_DINAMICO.md) | Sidebar configurable desde `config/sidebar.php`: alta de módulos, indicadores de mantenimiento |
| [`GEMINI_SETUP.md`](GEMINI_SETUP.md) | Configuración de la API de Google Gemini para TitoBot |
